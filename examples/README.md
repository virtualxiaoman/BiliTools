# 示例目录

所有命令都在项目根目录执行。

## 最简单的使用方式

扫码登录并下载一个视频：

```bash
python -m examples.quick_start
```

修改 `examples/quick_start.py` 中的 `BVID` 即可更换视频。

## 按功能查看

| 文件 | 功能 | 默认行为 |
|---|---|---|
| `quick_start.py` | 登录 + 下载视频 | 会扫码并下载一个视频 |
| `video.py` | 视频信息、下载、封面、多P、合集 | 查询视频信息 |
| `favorite.py` | 收藏夹查询和下载 | 查询收藏夹 |
| `archive.py` | 合集查询和下载 | 查询合集 |
| `up.py` | UP 主投稿查询和下载 | 查询投稿列表 |
| `account.py` | 登录状态和多账号 | 查询状态和账号 |
| `history.py` | 历史记录和导出 | 导出少量历史记录 |
| `user.py` | 用户信息 | 查询用户信息 |
| `rank.py` | 热门、排行榜和新视频 | 查询榜单 |
| `dressup.py` | 表情包、收藏集和装扮 | 搜索装扮 |
| `interactions.py` | 评论、私信、老粉签约 | 不自动执行写操作 |

批量下载、评论、私信和签约等行为请先检查示例中的参数，再手动调用对应函数。
