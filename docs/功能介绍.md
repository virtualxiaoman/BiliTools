# BiliTools 功能介绍

> BiliTools 是一个用 Python 操控 B 站（bilibili）的工具集，定位为**后端 SDK + 桌面 GUI + 命令行**三位一体：
> 底层是分层清晰、可被命令行 / Web / GUI 等多种前端稳定调用的 SDK；上层附带一个基于 PySide6 的桌面客户端，开箱即用。

---

## 一、项目简介

BiliTools 从「示例脚本集合」重构为「分层 SDK」，核心设计原则：

- **统一请求层**：所有 API 请求走 `BiliSession`，自动注入 User-Agent / Referer / Cookie，统一检查接口返回码，传输层失败自动重试。
- **类型化数据模型**：业务数据用 dataclass 表达（`VideoInfo`、`UserInfo`、`HistoryPage` 等），不再散落为手写字典。
- **统一异常体系**：失败一律抛异常（`BiliError` 及子类），调用方（尤其是 GUI）可以精确判断「未登录 / 风控 / 视频不存在 / ffmpeg 缺失」等失败原因。
- **路径统一管理**：cookie、输出目录等路径锚定在 `src/config/path.py`，支持 PyInstaller 打包后运行。
- **多端可用**：同一套服务层可被命令行（`main.py`）、桌面 GUI（`frontend/pyside6`）、示例脚本（`examples/`）调用。

## 三、功能详解

### 1. 视频下载（VideoService）—— 核心能力

#### 1.1 下载范围全覆盖

| 场景 | 方法 | 说明 |
|------|------|------|
| 单视频（含音频合成） | `download_video_with_audio(bvid)` | 默认最高清晰度，文件名自动为 `[标题](BV号).mp4` |
| 仅视频流 | `download_video(bvid)` | 无音频 |
| 仅音频流 | `download_audio(bvid)` | 适合缓存听歌，输出 `m4a/opus` 等 |
| 封面 | `download_cover(bvid)` | 输出 `[标题](BV号).jpg/png` |
| 指定分P | `download_video_with_audio(bvid, page=2)` | 只下第 2P，文件名含 P 序号 |
| 全部分P | `download_all_pages(bvid)` | 多P视频一次下完 |
| 整个合集 | `download_season(bvid=…, season_id=…, mid=…)` | 从合集内任一视频进入，或按 sid 直达（支持他人合集） |
| 整个收藏夹 | `download_fav(fid, mode=…)` | 全部视频或仅音频，保存到 `<收藏夹名>/` |
| UP主全部投稿 | `download_up(mid, mode=…)` | 全部视频或仅音频，保存到 `<UP主昵称>/` |
| **统一下载入口** | `download(bvid)` | 只传 bvid：属于合集 → 下整个合集；单视频 → 下该视频（含分P），自动选最高清晰度 |

#### 1.2 清晰度体系

内置 `VideoQuality` 枚举，覆盖 360P 到 8K：

```
P360 / P480 / P720 / P720_60 / P1080 / P1080_PLUS / P1080_60
HD4K（4K）/ HDR / DOLBY（杜比视界）/ HD8K（8K）
```

选择语义为**精确匹配**：指定 `P1080` 时，即使视频有 4K 源也只会下载 1080P；目标档位不存在时自动回退到最高可用档。

#### 1.3 音视频合成

- 基于 B 站 DASH 流，视频流与音频流分离下载，再用 **ffmpeg** 合成单文件；
- 合成前预检 ffmpeg，缺失时**提前报错**（`FFmpegNotFoundError`），避免白下几十 MB；
- 支持 `keep_parts=True` 保留合成前的临时流文件。

#### 1.4 下载健壮性

- **断点续传**：网络中断后自动用 `Range` 头从已下载位置继续，最多重试 3 次；
- **防风控节流**：批量下载时短停 + 每 10 个未命中缓存的视频随机休息 1~3 秒；
- **风控重试**：触发 -412/-403 时随机退避后重试（最多 3 次）；
- **跳过不可见视频**：-404 不存在 / 62002 稿件不可见的视频自动跳过，不中断批量任务；
- **本地缓存命中**：已下载过的文件直接命中返回（`cached=True`），不重复请求网络；
- **进度显示**：命令行输出 `[i/n] [文件名] [清晰度]: a/bMB (p%)`，GUI 有实时进度条。

### 2. 登录（LoginService）

- **扫码登录**：`generate_qr()` 生成二维码（`qrcode` 库保存为 PNG）→ `poll()/poll_full()` 无阻塞轮询状态码 → `save_cookie()` 保存 cookie；
- **一键登录**：`qr_login()` 内部阻塞完成「生成 → 轮询 → 保存」全流程；
- **状态查询**：`get_login_state()/get_mid()/get_uname()`；
- **cookie 管理**：自动从 set-cookie 提取 `SESSDATA / bili_jct / DedeUserID` 等关键字段，保存后刷新进程级缓存，新 cookie 全局立即生效。

### 3. 历史记录（HistoryService）

- 游标式分页获取历史记录（`get_history_page` / `get_history_all`），支持按业务类型筛选（稿件 / 直播 / 文章）；
- **失效视频查找**：`get_invalid_video(bv)` —— 视频已失效无法正常访问时，仍可从历史记录里找回其信息；
- **导出 xlsx**：`save_video_history_df()` 用 pandas 导出观看进度、时长、观看时间，可选附加点赞/投币/收藏与视频详情，支持追加去重。

### 4. 用户与互动

- **用户信息**（`UserService.fetch_info`）：昵称、头像、签名、关注数、粉丝数、等级；
- **老粉签约**（`ContractService.add_contract`）：一键成为 UP 主的老粉；
- **发表评论**（`ReplyService.send_reply`）：支持 BV 号或 av 号，自动带 csrf；
- **发送私信**（`MessageService.send_msg`）：支持文字消息（可扩展图片/撤回类型）。

### 5. 排行与内容发现（RankService）

- 综合热门（`get_popular`）；
- 排行榜（`get_ranking`）；
- 分区新视频（`get_new`）。

### 6. 收藏夹与合集（FavService / ArchiveService）

- **收藏夹**：`get_fav_info()` 收藏夹详情（名称/数量）、`get_fav_bv()` 一次性返回全部视频 BV 号；输入为 media_id；
- **合集**：`get_season_by_sid()` 按 sid 取合集完整结构（自动翻页）、`get_bvlist_by_sid()`、`get_sidlist_by_mid()` 列出用户全部合集；支持**任意 UP 主**的合集（mid 用于定位）。

### 7. 桌面 GUI（frontend/pyside6）

基于 PySide6 的现代桌面客户端，无边框窗口，含三个页面：

- **下载页**：
  - 五个来源页签：**视频 BV / 收藏夹 / 合集 / UP主 / 装扮**，均支持「直接传 id 或完整链接」，链接还会自动解析 `?p=分P` 并切换范围；
  - 装扮页签：关键词同时搜索表情包 / 收藏集 / 主题装扮，勾选可批量下载，支持并发线程与多账号分流；
  - 范围选择：全部P / 单P（P 序号输入框支持方向键微调）；
  - 类型选择：视频（含声音）/ 仅音频；
  - 清晰度下拉：360P ~ 8K 全档位；
  - 自定义保存目录 + 「打开输出文件夹」；
  - 多任务进度面板：每个任务独立进度条 + 阶段提示（下载流 → 合成中）；
  - 彩色里程碑日志：普通 / 进度 / 警告 / 错误 / 成功 分色显示。
- **登录页**：二维码扫码登录（自动生成、可重新生成）、登录状态展示、退出登录。
- **设置页**：默认保存目录、默认清晰度、默认类型、ffmpeg 检测、浅色/深色主题、日志行数与时间戳、快捷打开输出/日志/cookie 目录。

GUI 工程特性：

- **任务去重**：参数完全相同的任务已在运行/排队时不重复提交；
- **并发下载**：内容不同即新开线程，多任务并行；
- **登录门禁**：未登录时阻止下载并引导到登录页；下载失败若因登录失效会自动提示重登；
- **全局异常兜底**：异常钩子保证「永不闪退」；
- **深浅主题**：调色板 token + QSS 模板生成，全应用统一；
- **设置持久化**：JSON 保存到 `assets/ui_settings.json`。

### 8. 命令行入口（main.py）

```
python main.py info  BV号    # 获取视频信息（标题/UP主/播放/弹幕/评论/标签）
python main.py video BV号    # 下载视频（含音频）
python main.py cover BV号    # 下载封面
python main.py rank          # 获取热门视频列表
```

## 四、项目结构

```
BiliTools/
├── main.py                # 命令行入口
├── bilitools_gui.py       # 桌面 GUI 启动入口（PyInstaller 打包 / 双击运行）

├── examples/              # 使用示例（examples/quick_start.py）

│   ├── api/               # 统一请求层（BiliSession）、wbi 签名、统一异常体系
│   ├── config/            # 路径锚点（path）、常量、Cookie 管理（含进程级缓存）
│   ├── models/            # 业务数据模型（dataclass）
│   ├── services/          # 业务服务（核心 API，按业务分文件）
│   ├── urls/              # API URL 统一管理（按业务分文件）
│   └── util/              # BV/AV 转换、文件名清洗、下载工具（断点续传）、进度显示
├── frontend/
│   ├── pyside6/           # 桌面 GUI（PySide6）：页面 / 组件 / 工作线程 / 主题 / 信号
│   └── old/               # 旧版 GUI（已弃用，保留参考）
├── assets/                # 静态资源
│   ├── cookie/            # 扫码登录后的 cookie（qr_login.txt / qr_login.png）
│   └── imgs/              # 图标等
├── output/                # 下载输出
│   ├── video/             # 视频/音频/封面下载目录
│   └── history/           # 历史记录 xlsx 等表格
├── docs/                  # 项目文档
├── tests/                 # pytest 测试（单元测试 + 真实网络测试）
└── requirements.txt       # 运行时依赖
```

### 分层架构说明

```
前端（命令行 main.py / 桌面 GUI / 示例脚本）
        │  调用
        ▼
src/services/   业务服务层（面向场景的封装）
        │  使用
        ▼
src/models/     数据模型层（dataclass）
src/api/        统一请求层（BiliSession / wbi 签名 / 异常体系）
src/urls/       API 地址管理
src/util/       工具层（下载 / 命名 / 进度）
src/config/     配置层（路径 / 常量 / cookie）
```

## 五、快速上手（SDK 方式）

```python
from src.services import LoginService, VideoService
from src.models import VideoQuality

# 1. 扫码登录（只需一次，cookie 保存到 assets/cookie/qr_login.txt）
LoginService().qr_login()

# 2. 获取视频信息（返回 VideoInfo 数据模型）
service = VideoService()
info = service.fetch_info("BV1ov42117yC")
print(info.title, info.owner.name, info.stat.num_dm)

# 3. 下载视频（默认最高清晰度 4K，含音频合成）
result = service.download_video_with_audio("BV1ov42117yC")
print(result.path)

# 4. 统一下载入口：自动决定范围（合集 → 整个合集；单视频 → 该视频含分P）
service.download("BV1ov42117yC")

# 5. 分P / 合集 / 收藏夹 / UP主
service.download_video_with_audio("BV1Q43w6QETb", page=2)   # 只下第2P
service.download_all_pages("BV1Q43w6QETb")                   # 下载全部分P
service.download_season(season_id=8683221)                   # 按 sid 下载合集
service.download_fav(3953119978, mode="audio")               # 收藏夹仅音频
service.download_up(249056021)                                # UP主全部视频
```

更多示例见 `examples/quick_start.py`（`python -m examples.quick_start`）。

## 六、运行环境与依赖

| 依赖 | 用途 |
|------|------|
| `requests` | 网络请求 |
| `pandas` + `openpyxl` | 历史记录导出 xlsx |
| `pillow` + `qrcode` | 二维码生成与展示 |
| `PySide6` | 桌面 GUI（`python -m frontend.pyside6`） |
| **ffmpeg**（系统安装，加入 PATH） | 音视频合成，**无法用 pip 安装** |
| `pytest`（开发） | 测试 |

安装依赖：`pip install -r requirements.txt`

运行测试：

```bash
pytest tests/ -m "not network"   # 仅单元测试（不联网）
pytest tests/                    # 全部测试（含真实网络，需可访问 B 站）
```

可选打包为桌面 exe（需额外 `pip install pyinstaller`）：

```bash
pyinstaller bilitools.spec --noconfirm   # 产物在 dist/BiliTools.exe
```

## 七、注意事项

- 写操作（评论、私信、老粉签约）需要已登录且 cookie 含 `bili_jct`（CSRF token）；
- 部分高清晰度（4K / HDR / 杜比）需要大会员权限，无权限时自动回退到可用档；
- 频繁请求可能触发风控（-412），SDK 已内置退避重试与节流，但仍建议合理控制下载频率；
- 请遵守 B 站用户协议与相关法律法规，仅将本工具用于个人学习与合规用途。
